`template.sbp` / `template.sbpcfg` (a two-foundation blueprint, game version 1.2) are taken from the
test files of [satisfactory-file-parser](https://github.com/etothepii4/satisfactory-file-parser)
(MIT licence, © etothepii). They only provide the file header/version and object layout; the
foundations themselves are replaced by beams.

Better: put your own small blueprint that contains one *painted beam* here (or pass it with
`--bp-template`). Its version and its exact beam object are then used.
